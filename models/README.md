# Public watch movement models

The single in-site Watch Lab loads `ETA-6497-1-Movement-Gold-Jewels.glb` by default. Use the movement selector in the same lab to switch to `Seiko-NH35-Movement.glb` or to procedural escapement, single-/double-axis tourbillon, and minute-repeater studies. There is no separate GLB / LAB page; every movement is selected in this Watch Lab.

Keep the components separate so selection and exploded views continue to work. The ETA model retains names from the supplied STEP reconstruction; those names are not independently verified as official factory part names. The NH35 conversion contains 13 separate solid bodies with provisional labels. Metal and ruby finishes are presentation colors rather than claims about original factory materials. Verify upstream source redistribution terms before public release.
